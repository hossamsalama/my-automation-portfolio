## Screenshot: The AI Agent Architecture

**Project:** Inquiry Router Agent

**How this system works:**
1. **Input:** A raw customer inquiry is provided (via Set Variable / Webhook).
2. **Processing:** The "Make AI Agent" reads the text, classifies it (Sales/Support/Billing), and drafts a professional response.
3. **Action:** The agent autonomously uses its **internal Gmail Tool** to send the drafted response to the customer without human intervention.
4. **Result:** The user receives a fully drafted, classified, and sent email—all handled by the AI Agent in one click.

**Key innovation:** This system doesn't just "summarize" text. It makes a decision, takes action, and executes a real-world task (sending an email) completely autonomously.
