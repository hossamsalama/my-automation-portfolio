## Screenshot: The AI Agent Architecture

![Inquiry Router Agent](https://drive.google.com/file/d/1KJ7GMcUE2WJ1-kNKniTwA9TdW_5rjGry/view?usp=drive_link)

**How this system works:**
1. **Input**: A raw customer inquiry is provided (via Set Variable / Webhook).
2. **Processing**: The "Make AI Agent" reads the text, classifies it (Sales/Support/Billing), and drafts a professional response.
3. **Action**: The agent autonomously uses the Gmail tool to send the drafted response to the customer without human intervention.
